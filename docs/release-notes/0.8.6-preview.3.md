# Fairbeam 0.8.6-preview.3 (macOS preview)

This is the second published **macOS preview** for HF work (0.8.6-preview.2 was built for an
internal check and not published). It is a GitHub prerelease, not the Latest
release: installed apps are not offered it and the update feed stays on 0.8.5. Only a signed and
notarized Apple silicon DMG is provided; there is no Windows build of this preview.

## What to test

- **Units you pick.** Click `mm · GHz` in the designer's status bar (or open Settings) to pick the
  length unit (mm, cm, m, in, mil) and the frequency unit (kHz, MHz, GHz) that values are shown and
  typed in. A number may also carry its unit in any length or frequency field: `1 cm`, `7.1 MHz`.
  Designs are still saved in mm and GHz, and expressions such as `w/2` use those saved values.
  A parameter's unit label, the viewport scale bar, cursor coordinates and measurements follow the
  chosen units too. Results, plots and check messages still read mm and GHz.
  [#393](https://github.com/ismailakdag/fairbeam/pull/393),
  [#395](https://github.com/ismailakdag/fairbeam/pull/395)
- **HF examples.** Examples has a new HF group with center-fed strip dipoles at 7.1 MHz (40 m) and
  14.2 MHz (20 m). Their mesh is automatic, so `L`, `w` and `g` can be changed; each runs in about
  15 s on a laptop CPU. Example bands below 0.1 GHz are listed in MHz.
  [#392](https://github.com/ismailakdag/fairbeam/pull/392)
- **New design names.** A new design whose name is already used gets the next free file name
  (`empty_design_2`) instead of a "name exists" error.
  [#392](https://github.com/ismailakdag/fairbeam/pull/392)
- The "run too long" explanation says why runs below about 100 MHz get long with millimeter
  details, and technical drawings have scales down to 1:1000 so HF antennas fit on a sheet.
  [#392](https://github.com/ismailakdag/fairbeam/pull/392)

Everything in [0.8.6-preview.1](0.8.6-preview.1.md) is included.

## Numerical status of HF examples

The HF dipoles run to their energy stopping criterion and produce complete, finite S11 results.
This shows that the HF path executes; it is **not** a numerical validation. A comparison against
an independent solver has not yet converged, so these results must not be treated as accurate.
The strip stands in for a wire; no mesh convergence is claimed, and S11 alone says nothing about
radiation efficiency or patterns.

## Installing and returning to stable

The preview replaces the installed Fairbeam: it has the same app name, bundle ID, settings,
workspace and managed runtime as the stable release, so it is not a side-by-side install. On its
first start it refreshes the Fairbeam package in the managed runtime.

To return to stable, install the 0.8.5 DMG from the
[0.8.5 release](https://github.com/ismailakdag/fairbeam-releases/releases/tag/v0.8.5). The updater
does not downgrade, so this step is manual. On start, 0.8.5 detects the different package version
and refreshes the managed runtime again.

Requirements: Apple silicon and macOS 27 or later. The app bundle declares macOS 13, but the
managed openEMS runtime pack requires macOS 27.

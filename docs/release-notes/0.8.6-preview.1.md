# Fairbeam 0.8.6-preview.1 (macOS preview)

This is a **macOS preview** for testing HF bands and the canonical unit labels. It is published as
a GitHub prerelease and is not the Latest release, so installed apps are not offered it and the
update feed stays on 0.8.5. Only a signed and notarized Apple silicon DMG is provided; there is
no Windows build of this preview.

## What to test

- Designer bands now accept HF frequencies, for example `f0 = 0.05` GHz, or an explicit
  2–50 MHz band from `f0`, `bw`, `f_min` and `f_max` parameters. Positive, ordered bands are
  still required. [#383](https://github.com/ismailakdag/fairbeam/pull/383)
- Lengths are always stored in millimeters and frequencies in GHz. The "Unit label" setting only
  annotates values; it does not convert them, so 10 entered in a mm field is 1 cm.
  [#383](https://github.com/ismailakdag/fairbeam/pull/383)

## Numerical status of HF examples

HF example dipoles (2–50 MHz, 5–9 MHz and 10–18 MHz) run to their energy stopping criterion and
produce complete, finite S11 results. This shows that the HF path executes; it is **not** a
numerical validation. A comparison against an independent solver has not yet converged, so these
results must not be treated as accurate. Energy termination is separate from mesh and boundary
convergence, and S11 alone says nothing about radiation efficiency or patterns.

## Installing and returning to stable

The preview replaces the installed Fairbeam: it has the same app name, bundle ID, settings,
workspace and managed runtime as the stable release, so it is not a side-by-side install. On its
first start it refreshes the Fairbeam package in the managed runtime.

To return to stable, install the 0.8.5 DMG from the
[0.8.5 release](https://github.com/ismailakdag/fairbeam-releases/releases/tag/v0.8.5). The updater
does not downgrade, so this step is manual. On start, 0.8.5 detects the different package version
and refreshes the managed runtime again.

Requirements: Apple silicon and macOS 27 or later. The app bundle declares macOS 13, but the
managed openEMS runtime pack requires macOS 27.

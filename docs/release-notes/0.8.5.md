# Fairbeam 0.8.5

Fairbeam 0.8.5 adds antenna and network analysis, sweep trends, saved requirements,
local mesh controls and retained near-field postprocessing. It also fixes Windows
runtime installation, desktop close decisions and macOS temporary-directory handling.
These notes describe the source changes since v0.8.4; installer and platform verification
receipts are recorded separately in the release handoff.

## Installation and desktop reliability

- Windows managed Python installation resolves the physical installation directory before
  creating Python links. This addresses the MSIX AppData path failure on a clean runtime
  installation; a failed repair remains an error rather than accepting an unusable Python.
  Runtime staging and cache containment checks remain in place.
  [#329](https://github.com/ismailakdag/fairbeam/pull/329)
- Quit and Close Window include running and queued Blender renders as well as simulations,
  with separate counts. A final activity check catches work started during an unsaved-work
  prompt. Unavailable or malformed activity requires explicit consent; Cancel preserves
  the application and its work. Published 0.8.4 installers are unchanged.
  [#330](https://github.com/ismailakdag/fairbeam/pull/330)
- Informational notifications use a persistent polite announcement region and announce the
  newest message, including repeated identical messages. Error announcements remain assertive.
  The earlier NVDA checks cover synthesizer delivery, not every screen reader or packaged WebView.
  [#333](https://github.com/ismailakdag/fairbeam/pull/333)
- Windows file registration and uninstall cleanup now check ownership before removing entries.
  A fresh-machine installation and association qualification remains tracked in
  [#166](https://github.com/ismailakdag/fairbeam/issues/166).
  [#352](https://github.com/ismailakdag/fairbeam/pull/352)

## Antenna, network and sweep analysis

- Radiation results add circular polarization quantities, selected pattern cuts and
  radiation-versus-frequency views. Stored angles, physical port identity, power reliability
  and missing data govern which quantities can be shown or exported. Detailed angular
  patterns remain distinct from coarse frequency samples.
  [#335](https://github.com/ismailakdag/fairbeam/pull/335)
- Network postprocessing adds phase and group delay, real or complex port-reference changes,
  matched-feed removal, mixed-mode mapping and ideal matching networks. The processed matrix
  is used consistently in its views and exports; original radiation, power and stored bundles
  are preserved. An analytical stopband fixture also avoids determinant cancellation without
  changing measured matrices or relaxing reciprocity checks.
  [#335](https://github.com/ismailakdag/fairbeam/pull/335),
  [#331](https://github.com/ismailakdag/fairbeam/pull/331)
- Sweep trends plot five metrics against the first parameter, with series for a second
  parameter and adjacent-point sensitivity. Tracking follows frequency within the selected
  band; ambiguity, failed jobs, missing samples and duplicate coordinates produce gaps rather
  than invented continuity. CSV exports preserve coordinates, job identity and exclusion
  reasons. Frequency tracking does not establish physical mode identity.
  [#337](https://github.com/ismailakdag/fairbeam/pull/337)
- Band objectives evaluate interior samples and interpolated band edges. Missing or nonfinite
  samples are penalized. Realized-gain and radiation-efficiency objectives require qualified
  convergence, matching frequency and consistent power data. Designer Array weights are
  independent of Viewer state and invalidate when their source changes.
  [#339](https://github.com/ismailakdag/fairbeam/pull/339)
- Small-antenna analysis uses the original single-port complex impedance for resonance,
  impedance-derivative Q and VSWR bandwidth. Enclosure size, electrical size and single-mode
  Chu/McLean references are qualified by available geometry and power evidence. Multiple
  crossings require selection; these diagnostics do not prove a physical mode or a limit.
  Native nonfinite energy is rejected before postprocessing.
  [#347](https://github.com/ismailakdag/fairbeam/pull/347)
- MIMO analysis adds S-parameter and field ECC, diversity gain, TARC, CCL and MEG with matrix,
  field, efficiency and identity checks. Array analysis adds tapers, scan-plane sweeps and
  gain, scan-loss, sidelobe and grating-lobe diagnostics. Ludwig-3 co/cross polarization and
  XPD require the necessary complex fields and angular coverage; missing evidence is not
  synthesized. Chart scaling and result-component lifetimes are also corrected.
  [#352](https://github.com/ismailakdag/fairbeam/pull/352)

## Design, mesh, materials and reusable results

- Mesh diagnostics identify the smallest interval and worst grading pair in model coordinates,
  with framing and qualified source suggestions. Local mesh boxes are supported consistently
  in Python and TypeScript, including conversion and final-grid diagnostics. Their grid lines
  can affect the global cell count and time step.
  [#335](https://github.com/ismailakdag/fairbeam/pull/335),
  [#352](https://github.com/ismailakdag/fairbeam/pull/352)
- An inset-fed patch starter exposes independent frequency, permittivity and thickness
  parameters. It is an analytical starting design, not a full-wave accuracy guarantee.
  Wideband Djordjevic-Sarkar materials carry their fit identity through preview and export;
  unsupported paths are refused. Fit error describes agreement with the assumed material model,
  not a material measurement. Optional network convergence checks retain physical port and
  excitation identity and do not count missing results as passes.
  [#335](https://github.com/ismailakdag/fairbeam/pull/335)
- Saved requirement masks have matching Python and TypeScript evaluations, optimizer
  conversion and reports. A numerical mask pass is separate from mesh and run qualification.
  [#352](https://github.com/ismailakdag/fairbeam/pull/352)
- Retained NF2FF inputs can be transformed at new frequencies without another FDTD run when
  their immutable inputs and source/mesh checks are satisfied. Missing raw inputs require a
  new run. Archive roots may sit below system aliases such as macOS `/tmp` or `/var`, or a
  Windows junction above the retained root. A link or reparse point at the retained root or
  below it is still rejected, including internal per-port and dangling links. Job, postprocess
  and CLI paths preserve containment checks.
  [#352](https://github.com/ismailakdag/fairbeam/pull/352),
  [#354](https://github.com/ismailakdag/fairbeam/pull/354)
- Restricted normal-incidence symmetric PEC/PMC stock cells support paired-reference
  reflection and material extraction. This does not qualify general Floquet/Bloch boundaries,
  patterned cells or oblique incidence. Elmer export corrects the inverse-permeability keyword;
  its S11 qualification remains open in [#140](https://github.com/ismailakdag/fairbeam/issues/140).
  [#352](https://github.com/ismailakdag/fairbeam/pull/352)

## Dependencies and research tooling

- Dependency maintenance updates Vite to 6.4.4, Puppeteer to 25.13.0 and the locked DOMPurify
  dependency to 3.4.17 to address the reported npm advisories. Dependency and license checks
  remain part of release validation; an earlier audit result is not a promise about future
  advisories. [#345](https://github.com/ismailakdag/fairbeam/pull/345)
- Release preparation also updates the locked Seroval dependency from 1.6.8 to 1.6.12,
  within Solid's existing compatible range, for the newly reported typed-array and RegExp
  serialization advisories. No forced override or major dependency upgrade is used.
  [Typed-array advisory](https://github.com/advisories/GHSA-f86p-h4j2-7qgj),
  [RegExp advisory](https://github.com/advisories/GHSA-9wx9-5pv9-3349)
- Reproducible research records now include the bounded finite PEC-strip reference and
  exterior-grid/TE10 diagnostics, with stricter timestamp, energy, frame and hash admission.
  The finite-strip record qualifies only its sampled normalized power, angular directivity
  and beamwidth; it does not establish impedance, absolute power or full-antenna convergence.
  Gaussian and finite RF TE10 trials did not pass the late-energy qualification gate.
  [#334](https://github.com/ismailakdag/fairbeam/pull/334),
  [#336](https://github.com/ismailakdag/fairbeam/pull/336),
  [#338](https://github.com/ismailakdag/fairbeam/pull/338),
  [#343](https://github.com/ismailakdag/fairbeam/pull/343)
- The optional PML grading-cell patch applies only to an explicitly patched private openEMS
  build. It does not change the installed runtime, default recipes, Designer schema or gallery,
  and does not qualify open-resonator Q. The manual research runner keeps its default 30-minute
  bound with an explicit 45-minute option. The Windows CI job budget is 60 minutes; individual
  test and solver time limits are unchanged.
  [#351](https://github.com/ismailakdag/fairbeam/pull/351),
  [#332](https://github.com/ismailakdag/fairbeam/pull/332),
  [#342](https://github.com/ismailakdag/fairbeam/pull/342)

## Release scope and remaining qualification

The cylindrical PML work in [#353](https://github.com/ismailakdag/fairbeam/pull/353) is excluded.
Open-resonator qualification remains open in
[#340](https://github.com/ismailakdag/fairbeam/issues/340); research diagnostics above must not
be interpreted as closing it. Other unresolved qualification work remains tracked in
[#70](https://github.com/ismailakdag/fairbeam/issues/70),
[#134](https://github.com/ismailakdag/fairbeam/issues/134), #140 and #166.
The hosted Windows proxy-download timeout and passing rerun are recorded as a nonblocking
investigation in [#355](https://github.com/ismailakdag/fairbeam/issues/355), not as a proven fix.

Version 0.8.4 remains a Windows-only, non-Latest release. Version 0.8.5 is prepared for Windows
and macOS: Windows publication uses `--latest=false`; Mac owns the macOS build, both-platform
verification and subsequent Latest promotion. Source checks and debug builds do not establish
installer, installed-runtime, upgrade or live-updater success. Those results belong to the
tagged release receipts; ordinary live updates are not offered while Latest points elsewhere.

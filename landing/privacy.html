Current release

Fairbeam 0.7.2 asks once whether you want to help count installs. Nothing is sent until you allow it. Sign-in remains disabled.

Update checks contact GitHub (fairbeam-releases). App and runtime downloads come from GitHub and upstream hosts. This website is hosted on Vercel. These services see your IP address and request data as any web server does; request-log retention is set by the hosting provider.

Startup update checks can be disabled in General settings. On Windows, the WebView2 component follows Microsoft’s own diagnostic-data settings.

Optional install counts

Questions about this notice: ismail@fairbeam.org.

Controller: İsmail Akdağ. Contact: ismail@fairbeam.org.

Purpose: count distinct installs per ISO week, app version, operating system and CPU architecture to prioritize platform support. Counts are not verified users. The cumulative sum of weekly distinct installs is an estimate, not an exact all-time distinct count.

Data and collection: only after you choose Allow, the desktop app sends a random install ID, app version, operating system, CPU architecture and report schema over HTTPS to fairbeam.org/api/ping, at most once every seven days. The UUIDv4 is generated locally from randomness, never from hardware, account, paths or network data. Nothing about designs, files, results or the user is sent.

The hosting provider processes your IP address to deliver the request. Fairbeam does not store IP addresses, user agents or request headers. Providers may keep infrastructure logs under their own policies.

Legal basis: explicit consent under KVKK Article 5 and consent under GDPR Article 6(1)(a), where applicable. Sharing is optional and does not affect app functionality. Choose Off in Settings › General › Install counts to withdraw at any time. Withdrawal stops future requests without affecting the lawfulness of earlier processing.

Recipients and processors: Vercel hosts the website and API and connects Redis storage for temporary weekly salted hashes and aggregates. GitHub hosts releases, updates and aggregate snapshots. No install IDs or hashes are written to GitHub.

International processing: provider servers may be outside Türkiye. Contact ismail@fairbeam.org for questions about processing and transfers.

Retention: aggregate totals are retained without a scheduled deletion date. Random salts rotate each ISO week (Monday 00:00 UTC). Salted ID hash sets and salts expire at that boundary after counts have been aggregated. No raw event log is created. Locally, the consent choice, random install ID and last attempt date are stored in app settings; failed requests also wait seven days.

Rights: KVKK Article 11 includes learning about processing, its purpose and recipients, seeking correction or deletion, notification to recipients, objecting to adverse automated decisions and seeking compensation for unlawful processing. GDPR Articles 15–21 provide access, rectification, erasure, restriction, portability and objection where applicable. There are no automated decisions based on usage reports.

To exercise your rights, write to ismail@fairbeam.org with your request. Do not send designs or post personal information in public issues. Reasonable identity verification may be needed. Totals have no installation identifier, so a particular installation’s contribution cannot be located or removed. You may complain to the Turkish Personal Data Protection Board (Kişisel Verileri Koruma Kurulu) or your EU supervisory authority, subject to applicable procedures.

Downloads and updates

GitHub release asset download counts are read as public totals by version and platform. They require no usage counting in the app and do not identify unique users or installs. Repeated downloads and updater requests can increase the totals.

Controls

Counting is off until you choose Allow. No thanks or dismissing the dialog saves your answer once. Turn counting off any time in Settings › General › Install counts. Turning it off deletes the local ID; turning it on again creates a new ID. Reset ID beside the switch also creates a new ID. Neither action resets the seven-day sending limit. FAIRBEAM_NO_TELEMETRY=1 overrides consent for that process. View what would be sent shows the report when due.

The website

The website source includes no analytics scripts or cookie-setting code. Theme and language preferences, and the browser demo’s settings and any drafts, are stored locally in your browser. Vercel hosting infrastructure still processes your IP address and request data, with retention set by the hosting provider.
